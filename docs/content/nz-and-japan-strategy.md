# Content Strategy — New Zealand and Japan, from India

Working document for `guides/new-zealand-visitor-visa-from-india` and
`guides/japan-visa-from-india`. Not reader-facing.
Research verified **21 August 2026** against Immigration New Zealand and Japanese
Ministry of Foreign Affairs sources.

Format follows `schengen-visa-from-india-strategy.md`. Two guides are covered together
because they were researched in one pass and share no facts — only the method.

# New Zealand

## 1. Content Strategy

| | |
|---|---|
| **Topic** | New Zealand Visitor Visa for Indian passport holders |
| **Primary keyword** | New Zealand visitor visa from India |
| **Search intent** | Informational with a strong cost sub-intent |
| **Content cluster** | Country Guides → New Zealand. Seventh entry |
| **User problem** | The advertised visa fee is not the cost. A second mandatory charge lands at payment, and it is not returned if the application fails |
| **Visaworx connection** | Visa Readiness primary; Documentation Review secondary |

### The angle

**The levy nobody budgets for, and that a declined application does not refund.** That second
clause is the real hook: it changes the economics of submitting a weak application, and almost
no competing content draws the consequence.

Secondary angle: the stay allowance is **cumulative**, not per visit. Six months in any twelve
on a multiple-entry visa catches people planning repeat family trips.

### Deliberate omissions

- **No processing times.** Immigration NZ publishes dynamic estimates that move.
- The fee is stated as "from NZD 441", matching the source's own wording, because it is a
  starting figure rather than a flat charge.
- One search result quoted the IVL as NZD 35. That is the pre-increase figure and was **not**
  used; the current NZD 100 was confirmed directly from the levy page.

# Japan

## 1. Content Strategy

| | |
|---|---|
| **Topic** | Japanese short-term tourist visa for applicants in India |
| **Primary keyword** | Japan visa from India |
| **Search intent** | Informational, with a large practical "how does this even work" component |
| **Content cluster** | Country Guides → Japan. Eighth entry |
| **User problem** | The visa is electronic. Travellers look for a sticker, do not find one, and assume failure — then arrive at the airport unable to display the notice |
| **Visaworx connection** | Visa Readiness primary; Documentation Review for itinerary quality |

### The angle

**There is no sticker, and the electronic notice must be shown on a phone with internet
access at the airport.** That second half is a genuine operational failure mode — flat battery,
no roaming on a connecting airport's network — and it is almost entirely absent from competing
content, which stops at "Japan has an eVisa now".

Secondary angle: the **fee is very low** (INR 500), which is worth stating precisely because
the gap between it and intermediary charges is so wide.

## 2. SEO Metadata

| Field | Value |
|---|---|
| **SEO title** | Japan Visa from India: eVisa, Fees and Airport Checks *(53 chars)* |
| **Meta description** | Japan issues Indian applicants an electronic visa, not a passport sticker, and it must be shown on a phone at the airport. The INR 500 fee and what to prepare. *(158 chars)* |
| **URL slug** | `japan-visa-from-india` |

## 3. Verified Facts and Citation Ledger

| Fact | Value | Official source | Verified |
|---|---|---|---|
| eVisa in India | started 1 April 2024 | MOFA / Embassy of Japan in India | 2026-08-21 |
| Scope | single-entry short-term stay for tourism, up to 90 days | MOFA | 2026-08-21 |
| Eligibility | Indian nationals and foreign nationals resident in India | MOFA | 2026-08-21 |
| Submission | through Japan Visa Application Centres operated by VFS Global | Embassy of Japan in India | 2026-08-21 |
| Output | visa issuance notice in electronic form, no sticker in the passport | MOFA | 2026-08-21 |
| Airport requirement | notice shown on a mobile device; internet access needed | MOFA | 2026-08-21 |

### Deliberate omissions

- **No processing time.** Not published consistently for this route.
- The itinerary emphasis is framed as how applications are read, not as a quoted rule, because
  it is editorial judgement rather than a published requirement.

## Shared notes

**Internal linking.** Both guides wire `relatedCountrySlugs` and `relatedServiceSlugs` and rely
on the guide template for Related Countries, Related Services, Related FAQs, the readiness CTA
and the expert CTA, so each body carries a single Visaworx connection.

**FAQ wording.** Five FAQs each rather than six, because padding to a number produces the
keyword-stuffed FAQ the framework warns against. Generic filler words are avoided in FAQ
questions — see the retrieval note in `uae-visa-from-india-strategy.md` for why that matters
at weight 3.

**Still outstanding in the country cluster:** Australia, South Korea. Australia remains blocked
on an unverifiable application charge, documented in `singapore-visa-from-india-strategy.md`.
