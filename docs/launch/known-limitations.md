# Visaworx Known Limitations & Scope Boundaries

1. **No Direct Visa Processing or Filing**: Visaworx is an intelligence and consultation advisory platform. It does not file visa forms directly with embassy portals.
2. **No User Authentication**: Visaworx requires no user login, account memory, or persistent dashboard.
3. **Session-Only Memory**: Consultation and readiness state reside in `sessionStorage` and are cleared immediately upon submission or session termination.
4. **Official Authority Verification Required**: Embassy requirements and fees are subject to change without notice. All guides urge applicants to verify current rules with government portals.
